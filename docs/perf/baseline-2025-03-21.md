# Data plane load baseline (template)

Record p50 / p95 latency and error rates after running k6 against a stable environment (same machine class, warmed pools).

## Environment

- API: `helix-data-plane` (Docker or `cargo run --release` from `data-plane/`)
- Redis: optional (`REDIS_URL` set in Compose)
- Target DB: PostgreSQL (version: ___)
- k6 version: ___

## Commands

```bash
cd helixDB
docker compose up -d --build

export DATA_PLANE_URL=http://127.0.0.1:9847
export DATA_PLANE_API_KEY=   # if configured on server
export PG_URL=postgresql://USER:PASS@host.docker.internal:5432/DBNAME
# If API runs in Docker, use host.docker.internal (Mac/Windows) or host IP for PG_URL.

k6 run scripts/k6/data-plane-smoke.js
```

Optional: add a second scenario with paginated rows once you pick a real `schema.table` present in your DB (duplicate stage in `data-plane-smoke.js`).

**Vegeta (alternative):** generate a targets file with `POST`/`GET` lines including bodies for connect and query, then `vegeta attack -duration=30s -rate=50 | vegeta report` (see [https://github.com/tsenart/vegeta](https://github.com/tsenart/vegeta)).
