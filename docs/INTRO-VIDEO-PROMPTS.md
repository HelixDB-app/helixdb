# pgStudio Intro Video — AI Prompts

Use these prompts in **Runway Gen-3**, **Pika**, **Sora**, **Kling**, or similar AI video tools to create a minimal, high-quality macOS-style intro for **pgStudio** (Database Admin Panel).

---

## Core style (use in every prompt)

- **Style:** Minimal, premium, next-gen. Apple macOS 26 / Sequoia-inspired. Frosted glass (glassmorphism), soft gradients, subtle motion.
- **Background:** Deep charcoal / slate gray (`#1c1c1e`–`#2c2c2e`) or soft dark blue-gray. Optional: very subtle grid or dot pattern, blurred.
- **Quality:** 4K, 24–30fps, smooth motion, no text unless specified. Max quality, cinematic.

---

## Prompt 1 — Logo reveal (glass orb)

```
Minimal Mac app intro, 5 seconds. Dark slate gray background (#1c1c1e) with very subtle frosted glass grid pattern, soft blur. Center: a single frosted glass sphere, translucent, catching soft blue-white light. Sphere gently pulses with a faint glow, then the pgStudio logo fades in inside the sphere. Camera slowly pushes in. No text except logo. Apple-style glassmorphism, macOS 26 aesthetic. 4K, cinematic, smooth motion.
```

## Tips for best results

1. **Tool settings:** Choose “realistic” or “cinematic”; avoid “cartoon” or “stylized.” Set resolution to max (4K if available).
2. **Length:** Keep clips 5–8 seconds; extend or loop in CapCut / DaVinci / Premiere.
3. **Logo:** If the AI doesn’t render “pgStudio” well, generate **without text** and add the logo in post (e.g. with a glass/blur overlay to match).
4. **Music:** Add a short, minimal sound design or soft pad (e.g. “minimal tech intro music, 5 seconds”) in a separate AI audio tool or library.
5. **Export:** MP4, H.264 or HEVC, 4K, 24–30fps for use in the app or on the web.
